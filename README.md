# The Arnold Institute of Broscience

Public website for The Arnold Institute of Broscience, a personal, non-commercial n-of-1 health research project.

- `index.html` – landing page
- `privacy.html` – Privacy Policy (generated from `policy.md` by `build.py` using Python-Markdown)
- `research/` – research notes (`build_research.py` builds `the-way-back-to-the-table.html`); SVG art in `research/assets/`
- `assets/fonts/` – self-hosted fonts (SIL Open Font License, see the OFL files)
- `style.css` – styles

Plain static HTML/CSS: no JavaScript, trackers, analytics, cookies, or external resources. This repository contains no personal health data or credentials.
